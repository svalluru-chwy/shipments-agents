# Shipment Consolidator Data Dictionary

## Briefing Components

| Component | Purpose |
|-----------|---------|
| Headline | One-sentence summary for quick scanning |
| Key Findings | Prioritized issues requiring attention |
| Actions | Specific steps with owners |
| Talking Points | Customer communication guidance |

## Severity Levels

| Level | Definition |
|-------|------------|
| HIGH | Immediate customer impact, requires same-day action |
| MEDIUM | Notable issue, requires this-week resolution |
| LOW | Minor concern, monitor and track |

## Urgency Levels

| Urgency | Timeframe |
|---------|-----------|
| IMMEDIATE | Today, within hours |
| SHORT_TERM | This week |
| MONITORING | Ongoing observation |

## Action Owners

| Owner | Responsibility |
|-------|----------------|
| CAT | Customer Action Team - customer outreach |
| OPS | Operations - internal process changes |
| CARRIER | Carrier escalation required |
